# Examples

## One photo

```text
Use $child-crayon on this photo. Preserve the hairstyle, outfit, and pose, but keep the face in the fixed minimal grammar. Return one final image.
```

## Multiple references

```text
Use $child-crayon on these three photos. Photo 1 is the composition. Photos 2 and 3 only clarify hairstyle and glasses. Each real person must appear exactly once.
```

## Chinese

```text
用 $child-crayon 把这些照片画成固定的儿童蜡笔涂鸦。第一张作为构图，其他照片只补充人物特征；不要拼贴、不要重复人物，只输出一张最终图。
```

## Targeted regeneration

```text
Use $child-crayon to retry the previous result. Keep all people, clothes, pose, and composition unchanged. Fix only the line quality: thicker, wobblier, repeatedly traced blunt black crayon, with rough broken edges instead of smooth digital outlines.
```
