# Contributing

Contributions are welcome when they improve repeatability without weakening the fixed visual identity.

Good contributions include:

- a reproducible failure case with privacy-safe or properly licensed references;
- a tighter subject-analysis rule;
- a QA rule that catches a real regression;
- a targeted recovery instruction;
- documentation and translation improvements;
- optional canonical style anchors that you have the right to redistribute.

Please avoid:

- silently changing the visual grammar into a different art style;
- adding realistic facial detail for “similarity”;
- committing private family photos or images without redistribution rights;
- adding unrelated image-generation workflows to this repository.

If a contribution intentionally changes the visual language, propose a new style version rather than silently mutating `CHILD_CRAYON_V1`.
