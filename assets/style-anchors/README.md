# Style Anchors

Place 3–6 **real generated outputs that you consider canonical** in this directory.

Recommended filenames:

```text
anchor-single.png
anchor-couple.png
anchor-family.png
anchor-group.png
```

The Skill treats these images as the visual center of `CHILD_CRAYON_V1` while the written rules in `skills/child-crayon/references/style-spec.md` remain hard constraints.

## Good anchors

Choose images that clearly show:

- oversized irregular round heads;
- tiny dot-feature faces;
- pale-pink circular cheek patches;
- blunt repeated black crayon contours;
- loose low-saturation fill with obvious white paper gaps;
- mostly uncolored skin;
- warm group interaction;
- sparse white-paper background.

Avoid anchors that already contain style drift, because a visual reference can amplify that drift more strongly than text can correct it.
