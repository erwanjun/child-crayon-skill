# Evals

This repository treats the style as a reproducible workflow, not only a prompt.

A practical regression set should eventually include permission-cleared photos covering:

1. single person;
2. couple;
3. parent + child;
4. family of 3–5;
5. larger group;
6. multi-photo references of the same people;
7. glasses / hats / bouquets / distinctive accessories;
8. partial occlusion;
9. side-facing subject;
10. meaningful environment versus cluttered environment.

For each case, record:

- expected unique-person count;
- primary composition image;
- supporting references;
- required relationship invariant;
- required identity cues;
- expected background policy;
- QA failures, if any.

Use `cases.example.yaml` as a starter schema. Do not commit private or unlicensed personal photos to a public repository.
